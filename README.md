Controls

Player 1 (Left Paddle):

UP – Move paddle up.

DOWN – Move paddle down.

Player 2 (Right Paddle):

A – Move paddle up.

B – Move paddle down.

Main Menu

START – Start a new game.

SPEED – Choose the ball speed (1–5).

WIN SCORE – Set the winning score (1–25).

Menu Controls:

UP / DOWN – Navigate the menu.

LEFT / A – Decrease a setting.

RIGHT / B – Increase a setting.

A – Select START.
